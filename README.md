This project marks a milestone between friends and that hard work can make hard problems go away! 


Flotmand started as an intern joke but became the cornerstone and describes the meaning of friendship and acceptance.

This app is for 6 friends who month after month has celabrated eachtothers componany by meeting up once a month for a dinner night. 


The purpose of this app is to collect everything we need into one little pakage. 

# ❔ What is this app about?

Concretely speaking this app lets us keep track of all our dinner night events, letting us know who's up next, Location of the event, who will participate and hopefully much more to come! 

if you are interested in following the roadmap, i made a poorly public [Trello board]([url](https://trello.com/b/1Xu4SSJk/flotmand-app))

# ⚙️ What makes this app soecuial? 

Unlike many other vibe coded app, i strove for consistent and consise architecsture. I also make sure to follow the best practices whether it is state handling navigation and logic in general. 
This is very loosely based on the Now in Android Repo.
