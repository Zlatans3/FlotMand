# FlotMand

## Authentication

This app uses **only Google account login** for authentication. No other login methods (email, phone, password, etc.) are supported or available.

- Users must sign in with their Google account to access the app.
- If Google Play Services are unavailable, login will not be possible.
- All UI and navigation are designed for Google-only authentication.

### Developer Note
If you plan to add other authentication methods, please update this documentation and review all UI/UX flows accordingly.
